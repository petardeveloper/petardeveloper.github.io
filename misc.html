About this tape

format
Plain HTML, CSS and JavaScript. No frameworks, no build step. View source, it's all there.
tracking
No cookies, no analytics. The only things it remembers are your fx and sound settings, the tape counter, and that you already sat through the intro once. All of that stays in your own browser. The fonts do load from Google, so Google sees that request.
special fx
The spinning coffin on the home page is a tiny software renderer. Every frame gets drawn pixel by pixel into a 160x120 canvas and then stretched up, wobble and all. The grain on top is the same trick, just random pixels.
sound
On from your first click (browsers don't let a page make noise before that). Every beep and clunk is synthesized right in the browser, there are no audio files. The SND button shuts it up and it remembers.
type
UnifrakturMaguntia, Pirata One, VT323, EB Garamond and Permanent Marker, from Google Fonts.
broadcast
Hosted for free on GitHub Pages.
warning
Contains flicker. If it gets to be too much, the FX button in the header turns it off, and it remembers. If your system is set to reduce motion it starts off anyway.
